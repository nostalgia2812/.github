      Setup required for live calls & SMS
      
                
      Running in Demo Mode
      
                
      
                  Set the environment variables below on your backend to enable real phone calls
                  and SMS via Twilio (free trial available — open-source SDK).
                
      
              
      
              
      
            
      
            
      
              Quick-start instructions
              
        
                
      1. Sign up at twilio.com — free trial includes $15 credit and a phone number.
        2. 
                
      2. Copy TWILIO_ACCOUNT_SID and TWILIO_AUTH_TOKEN from the Console dashboard.
        3. 
                
      3. Buy or verify a number under Phone Numbers → Manage. Set it as TWILIO_PHONE_NUMBER (E.164, e.g. +15005550006).
        4. 
                
      4. Create a TwiML App (Voice → TwiML Apps → Create). Set Request URL to https://<your-host>/api/comms/voice/twiml. Copy the App SID as TWILIO_TWIML_APP_SID.
        5. 
                
      5. Create an API Key (Account → API Keys → Create). Save the SID as TWILIO_API_KEY and the secret as TWILIO_API_SECRET.
        6. 
                
      6. On the phone number's configuration page set the Messaging webhook to POST https://<your-host>/api/comms/webhook/sms and the Voice webhook to POST https://<your-host>/api/comms/webhook/voice.
        7. 
                
      7. Restart the backend. The banner will disappear when all vars are detected.
        8.
